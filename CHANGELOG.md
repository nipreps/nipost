# 0.1.0 — 2026-10-19

## Added

- `nipost.resample_image()` and related API for resampling images from a raw dataset
  using minimal derivatives.
- `nipost.bids.collect_derivatives()` to perform spec-driven discovery of derivatives
  in a BIDS Derivatives dataset.
